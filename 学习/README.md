# 学习：症状组合 → 可能方向 → 红旗

> **红线：这里记的是「线索」，不是「诊断」。看到自己像某条，别自己给自己下结论——去医院。**

---

## 怎么记（格式）

| 症状组合（线索） | 可能方向（只写大类，不写确诊） | 红旗（必须马上送医） |
|---|---|---|
| 例：持续胸痛 + 出冷汗 + 放射到肩臂 | 心源性问题方向 | **立即急诊/120，不要等** |

## 已学内容（持续追加）

- **（待填充）** 从案例里对上的组合——按上面格式一条一条记。
- **学到的逻辑**：哪些组合单看像小问题、合看像大事；哪些是「先排除致命再慢慢查」。

## 学习纪律

1. **只写方向不写病名**（写病名就是越界当医生）。
2. **每次新案例回来：对得上 → 确认；对不上 → 推翻重学。** 没有结论是终审的。
3. **被推翻的结论不删，标「已推翻 + 原因」**——那本身是学习。
