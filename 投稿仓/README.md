# 投稿仓（原始层）

> **这里收原始投稿，不急着判断真假对错——先让它落下来。**

## 规则

- 匿名投，**不写真实姓名/联系方式/住址/单位**。
- **照收**：投过来就落在这，不删、不改（只做匿名脱敏）。
- **投稿仓不终审**：这里的东西要经过 **大量用户一起筛**——对得上→进数据库，对不上→留在这里作「当初为什么觉得对」的素材。

## 怎么投

复制 `../案例\模板_匿名投稿.md`，填好发到 issue / 邮件（渠道见上级 README），**不需要留身份**。

## 为什么会出现在这

**筛选的过程就是学习**：一个人投、一群人验，验过的进库，验不过的留下当反例。**这里不是垃圾桶，是学习的第一现场。**
