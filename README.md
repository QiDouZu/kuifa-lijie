# 匮乏是理解的角度

> **匮乏不是缺陷，是理解人怎么活过来的那扇门。**
> 这个仓库装的是**前人走过的路、学到的逻辑、和过程**——匿名投稿，谁也不认识谁。**逻辑的推测在学习里会被证伪，会被自己优化。**
> **不只是病：这是开源知识库。谁走过的路、怎么走的、哪一步以为对其实错了——都值得记。**

---

## 这里放什么

| 目录 | 放什么 |
|---|---|
| `案例\` | 匿名投稿的真实经历（不止病：任何「走过的路」——病、困境、摔过的坑、走过的弯路） |
| `学习\` | 从案例里蒸馏出的逻辑：**线索组合 → 可能方向 → 危险信号**；**可证伪、可自我优化** |
| `过程\` | 怎么学的、错在哪、结论怎么被新案例推翻重来（这一页证明「学习本身在证伪」） |

## 怎么走前人的路（蒸馏）

1. **读**：前人走过的路，先别评判，先看清他当时面对什么。
2. **抽**：从他这趟路里抽出「什么线索→通向什么方向」——**抽的是逻辑，不是复制结论。**
3. **套**：拿这套逻辑去套新的情况（新的人、新的病、新的困境）——**套不上，说明逻辑还不够用。**
4. **验**：新案例回来一对：**对得上=确认，对不上=推翻重学。** 没有结论是终审的，只有持续被修正的猜想。
5. **留**：推翻的不删，标「已推翻+原因」——**那是学习本身。**

> **以自己为基底**：AI 可以拿自己（一套框架、一种经验、一条走过的路）当底，去理解别人的路——**但底是参照，不是尺子**（匮乏实验：不能用「完备=正确」量「匮乏=另一种活法」）。

## 这个知识库本身就是回溯性重构

- **建立方式 = 回溯性重构**：不是先立结论再找案例，是**先有走过的路、再回头把逻辑写清楚**——**线上实时形态**：你正在走的这趟路，边走后边被记下，随时可回溯。
- **可以引用部分原话**（匿名投稿）：**引的是「当时怎么想、怎么走」的那部分原话**，不引身份；**原话是碎片，逻辑是拼图**——拼图归库里，碎片归匿名。
- **实时性就是它的价值**：**不是等到「想明白了」才记，是边记边被推翻重写**——这个仓库自己就是它的格式（跟 retcon-docs 一个道理）。

## 匿名规则（红线，先读这个）

1. **不写真实姓名、联系方式、住址、单位**——写「哪类人」，不写「哪个人」。
2. **投稿者不需要身份**：你投了，没人知道是你；**AI 也不猜投稿人是谁**，不反向追踪。
3. **能少写就少写**：只写对「学病」有用的身体和经历细节。

## 怎么学

- **案例 → 三条线**：症状组合、可能方向、红旗（什么信号必须马上送医）。
- **新案例回来**：对得上就确认，**对不上就推翻重学**——**没有永远正确的结论，只有持续被修正的猜想。**
- **学的是逻辑，不是照抄病例**：怎么从身体线索推到「该查什么」，不是背诵病名。

## 边界

- **不诊断、不替代医生**：这里的一切都是**学习材料**，不是诊断依据。
- **是猜病，不是断病**：发现「你可能有什么」只是线索，确诊永远在医生手里。
- **隐私第一**：投稿默认匿名分享，AI 不识别、不回推。
